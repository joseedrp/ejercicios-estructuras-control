# Ejercicios de Estructuras de Control

Seis ejercicios resueltos en Java en `EjerciciosEstructurasControl.java`:

1. Números pares del 1 al 100 usando `for`.
2. Números impares del 1 al 100 usando `for`.
3. Suma de los primeros 50 números naturales (1275).
4. Tabla de multiplicar del 1 al 10 usando `for`.
5. Factorial de un número usando `while`.
6. Mayor de tres números usando `if-else`.

## Cómo ejecutarlo

Con un JDK instalado, abre una terminal en la carpeta del archivo y ejecuta:

```sh
javac EjerciciosEstructurasControl.java
java EjerciciosEstructurasControl
```

Los ejercicios se ejecutan en orden y piden los números enteros necesarios. El factorial admite números de 0 a 20 para evitar desbordamientos del tipo `long`. El factorial de 0 es 1.
